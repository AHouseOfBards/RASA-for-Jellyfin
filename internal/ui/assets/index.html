RASA for Jellyfin

Let's make your server reachable from anywhere

RASA gives your Jellyfin server its own web address and a proper security certificate, sets up your router, and tells Jellyfin about it. It takes about seven minutes, and you only need to be at the keyboard for three of the steps.

You've set this up before. Running setup again will check everything over and repair whatever needs it.

Checking things over

Working out what your network can do. Nothing is being changed yet.

    Sign in to Jellyfin

    This must be the account you set Jellyfin up with. RASA needs administrator access to change your server's network settings, and your password is sent only to your own server.

    In Jellyfin: Dashboard → API Keys → add a key.

    Create your free address account

    Your web address comes from Dynu, who give them away free. The account is yours, not RASA's — nobody else can change or take your address.

    1. Open Dynu and create an account. It asks for an email address and a password.
    2. Once you're signed in, go to Control Panel → API Credentials.
    3. Copy the API key and paste it below.

    RASA stores this key on this computer only, protected by your operating system. It's what keeps your address pointing at your home connection after RASA is gone.
